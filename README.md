# 🧮 Easy Calculator (PWA)

A feature-packed, multi-mode **Progressive Web App (PWA)** built from scratch using pure HTML, CSS, and Vanilla JavaScript. Designed for high accessibility and everyday utility.

🚀 **[Click Here for Live Demo](https://mdalif027-tech.github.io/easy-calculator/)**

---

## ✨ Features

* **Multiple Calculation Modes:** 
  * Standard & Scientific Calculator
  * Sales & Interest (Simple & Compound)
  * Unit Conversions & Percentage Adjustments
  * Health & Utility: BMI & Age Calculator
* **Accessibility & Customization:** Customizable button sizes and dark/light background themes.
* **Offline Capability:** Built with a Service Worker (`sw.js`) and Web App Manifest (`manifest.json`) so it can be installed directly onto mobile or desktop devices and used fully offline.

---

## 🛠️ Tech Stack

* **HTML5** - Application structure
* **CSS3** - Custom styling & responsive layouts
* **JavaScript (ES6+)** - App logic & calculation engines
* **Service Workers & PWA Standards** - Caching & offline functionality
